# CFD_streakLine_FN
Questo repository presenta la discretizzazione di un dominio bidimensionale mediante il modello PSI–ZITA, finalizzata al calcolo delle streakline. La discretizzazione dell’operatore laplaciano è stata affrontata utilizzando sia metodi diretti sia metodi iterativi (SOR). Per integ temporale: 1) RK4 2) (AB2, AB3).
